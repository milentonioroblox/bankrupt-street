Bankrupt Street UI spec

An audit of the latest Nano Banana mockup, followed by the corrected screens, colour tokens and the exact recipe for building them in Roblox Studio. The mockups below are built in HTML to scale, so they show the real proportions on a 16:9 phone.

KeepVisual styleGlossy gradient buttons, thick outlines, white outlined text, labelled icons and the cream panels all work for Roblox.
RedoLayoutCopies the reference game's structure and puts buttons under the phone thumbstick. Too many controls at once.
Must changeShop contentsRandom crates with odds, bought bids and paid boosts break the GDD and Roblox's paid-random-item rules.

Design everything in pixels at 1280×720 and add one UIScale that scales the whole UI to the screen. On a typical phone the scale is about 0.55, so 28 px becomes about 15 px and an 88 px button about 48 px, both still readable and tappable.

Button recipe (Luau)

One helper builds every glossy button the same way, so the style never drifts. Put it in src/client/UI/Button.luau.

local Theme = {
	Outline = Color3.fromHex("1B1B2F"),
	Red    = { Color3.fromHex("FF4D4D"), Color3.fromHex("C8102E") },
	Gold   = { Color3.fromHex("FFE14D"), Color3.fromHex("F5A300") },
	Green  = { Color3.fromHex("7CFF5B"), Color3.fromHex("22B83A") },
	Blue   = { Color3.fromHex("5BC8FF"), Color3.fromHex("1E6FE8") },
	Purple = { Color3.fromHex("C77DFF"), Color3.fromHex("7B2FF7") },
	Pink   = { Color3.fromHex("FF6FD8"), Color3.fromHex("E0218A") },
}

local function makeButton(text: string, colour: { Color3 }, size: UDim2): TextButton
	local b = Instance.new("TextButton")
	b.Size = size
	b.BackgroundColor3 = Color3.new(1, 1, 1)
	b.AutoButtonColor = false
	b.Text = text
	b.FontFace = Font.fromEnum(Enum.Font.FredokaOne)
	b.TextSize = 30
	b.TextColor3 = Color3.new(1, 1, 1)

	local grad = Instance.new("UIGradient")
	grad.Color = ColorSequence.new(colour[1], colour[2])
	grad.Rotation = 90
	grad.Parent = b

	Instance.new("UICorner", b).CornerRadius = UDim.new(0, 18)

	local border = Instance.new("UIStroke")
	border.ApplyStrokeMode = Enum.ApplyStrokeMode.Border
	border.Color = Theme.Outline
	border.Thickness = 4
	border.Parent = b

	local textStroke = Instance.new("UIStroke")
	textStroke.ApplyStrokeMode = Enum.ApplyStrokeMode.Contextual
	textStroke.Color = Theme.Outline
	textStroke.Thickness = 3
	textStroke.Parent = b

	-- glossy highlight on the top half
	local shine = Instance.new("Frame")
	shine.BackgroundColor3 = Color3.new(1, 1, 1)
	shine.BackgroundTransparency = 0.6
	shine.BorderSizePixel = 0
	shine.Size = UDim2.new(0.88, 0, 0.42, 0)
	shine.Position = UDim2.new(0.06, 0, 0.06, 0)
	shine.ZIndex = b.ZIndex
	Instance.new("UICorner", shine).CornerRadius = UDim.new(0, 12)
	shine.Parent = b

	return b
end

Production order

  1. Build Theme.luau and the button helper first, then a UIScale script on the HUD.
  2. HUD: CashPanel, Timers, Store button, NavColumn, NextHouseBar. Hook them to the server state that M0 already pushes.
  3. Auction overlay and LiveAuctionChip (M1). Test on the phone emulator in Studio: iPhone SE landscape and a 16:9 Android.
  4. Crash and bankrupt states: tint, banner, stinger.
  5. Property shop and upgrade panels in in-game cash.
  6. Robux store last (M2), with the fixed items above and real product IDs.
  7. ForgeGUI makes the icons (house, shop bag, gift, trophy, shield, gavel) and panel header art. Text always stays as TextLabels.
